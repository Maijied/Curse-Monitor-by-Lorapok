What you get

A lean terminal board and agent plugin — not the VS Code extension. Surfaces Cursor usage where you work, including grouped reports.

CLI status / accounts / json / whoami

Pretty boxed board, live refresh, machine-readable JSON for agents, and multi-account list/switch across Cursor product folders.

Reports by model, Auto/API, surface

curse-monitor report groups model, autoApi, or surface over 7d, 30d, cycle, or mtd.

Bonus pool math

Included + bonus/agent credits → combined pool, remaining, and at-limit — so a “100%” included bar doesn’t hide leftover bonus.

Stale 100% detection

Yellow banner when the API shows 100% but pool remaining is still positive — catch misleading meters before you overreact.

Grok Bot plugin

Marketplace-ready skills under plugins/curse-monitor/ teach agents to run status, report, json, whoami, accounts, use, and watch.

Privacy-first

Token stays on your machine. Never printed, never written to JSON. Network only to api2.cursor.sh.

Honest limit: Cursor API does not expose per-model dollar spend. Model breakdown is local active-model / analytics grouping plus Auto/API meters — not a dollar split.

Install

Clone the repo, build, and link the curse-monitor binary. Requires Node.js 20+ (22+ recommended).

git clone https://github.com/Maijied/Curse-Monitor-by-Lorapok.git
cd Curse-Monitor-by-Lorapok
npm install
npm run build
npm link
curse-monitor report

Without linking: npm start -- report or node dist/cli.js report. Auth from Cursor session, CURSOR_TOKEN, or --token.
