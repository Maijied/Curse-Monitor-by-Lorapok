Install

git clone https://github.com/Maijied/Curse-Monitor-by-Lorapok.git
cd Curse-Monitor-by-Lorapok
npm install && npm run build && npm link
curse-monitor --help

Requirements: Node.js 20+ (22+ recommended for built-in node:sqlite) and a signed-in Cursor session, or a token via env / flag.

Commands

curse-monitor              # pretty status board (default)
curse-monitor status
curse-monitor watch [--interval 30]
curse-monitor json
curse-monitor whoami
curse-monitor --help
CommandPurpose
statusHuman-facing boxed board
jsonMachine-readable snapshot + richer metrics for agents
whoamiWhich Cursor product folder / email will be used
watchLive refresh every N seconds (default 30)

Library API

import {
  resolveAuth,
  fetchSnapshot,
  buildBudgetMetrics,
  resolveUsagePlanPool,
  formatStatusBoard,
} from "curse-monitor";

const auth = resolveAuth();
const snap = await fetchSnapshot(auth.accessToken, { email: auth.email });
console.log(formatStatusBoard(snap));

Endpoints (Bearer token): GET https://api2.cursor.sh/auth/usage-summary and GET https://api2.cursor.sh/auth/full_stripe_profile.
